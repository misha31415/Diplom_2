# 🔌 API-тестирование Stellar Burgers

## 📋 Описание

Проект по автоматизации тестирования REST API приложения Stellar Burgers.  
Покрытие ключевых эндпоинтов: создание пользователя, авторизация, создание заказов.

---

## 🛠 Технологии и инструменты

| Технология | Версия | Назначение |
|------------|--------|------------|
| **Java** | 11 | Язык разработки |
| **JUnit 4** | 4.13.2 | Фреймворк для тестирования |
| **REST Assured** | 5.3.2 | Отправка HTTP-запросов |
| **Allure** | 2.27.0 | Отчётность |
| **Jackson** | 2.15.2 | Сериализация JSON |
| **Lombok** | 1.18.30 | Генерация кода |
| **Maven** | 3.x | Сборка проекта |

---
## 🧪 Что покрыто тестами

### Создание пользователя
- Успешное создание уникального пользователя
- Создание пользователя, который уже зарегистрирован
- Создание пользователя без обязательных полей (email, password, name)

### Авторизация
- Вход под существующим пользователем
- Вход с неверным логином и паролем
- Вход с неверным паролем
- Вход с неверным email

### Создание заказа
- Создание заказа с авторизацией
- Создание заказа без авторизации
- Создание заказа с ингредиентами
- Создание заказа без ингредиентов
- Создание заказа с неверным хешем ингредиента
